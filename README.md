# 🐝 spellingbee — 拼字蜜蜂

一个纯本地的 Spelling Bee 单词游戏：7 个字母（1 个中心必用字母），拼出尽可能多的单词。

## 玩法

- 每一局随机生成 7 个字母，**第 1 个为中心字母，每个单词必须包含它**
- 单词要求：
  1. 至少 4 个字母
  2. 只能使用给出的 7 个字母（可重复使用）
  3. 必须包含中心字母
  4. 必须在内置词表里
- 计分：4 字母词 = 1 分；5 字母及以上 = 字母数；用遍全部 7 个字母的 **pangram（全字母词）** 额外 +7 分
- 段位按"得分占本局满分百分比"划分：新手上路 → 渐入佳境 → 稳步上升 → 表现不错 → 实力扎实 → 相当出色 → 了不起 → 令人惊叹 → 天才（70% 封顶）

## 安装与运行

仅需 Python 3.10+，无第三方依赖。

```bash
cd spellingbee
python -m spellingbee            # 开始游戏
python -m spellingbee --seed 42  # 用固定种子复现同一局
python -m spellingbee --answers  # 直接列出本局全部答案
python -m spellingbee --letters eadlnrt  # 自定义字母（第 1 个为中心字母）
```

游戏内命令：`:help` 帮助、`:rank` 当前段位、`:words` 已找到的词、`:quit` 结束。

## 创意点

- 生成器会**自动筛选**：随机字母组合必须至少有 15 个合法词且至少 1 个 pangram，否则重抽，保证每一局都好玩、可解
- `--seed` 让同一局可复现，适合和朋友比拼同一套题

## 已知限制

- 内置词表约数千常用英文单词（超出了原设想的 300 词，玩起来更顺手），但仍有大量合法英文词不在表内；遇到"词表里没有这个词"时是词表限制，不是拼错了
- 中心字母组合可能偶尔偏僻，靠生成器的 15 词 + pangram 保底来保证可玩性
